# Product Strategist Reference

Use this when `cy-idea-factory` evaluates whether the original idea is truly
high leverage.

## Questions To Ask

- is the current idea high leverage or incremental?
- is there a simpler version with most of the value?
- is there a more ambitious version that changes the product materially?
- is there an adjacent opportunity worth considering instead?

## Evaluation Framework

Score each option across:

- impact
- reach
- frequency
- differentiation
- defensibility
- feasibility

## Output Expectations

Produce up to 3 alternatives:

- one more ambitious version
- one simpler version
- one adjacent opportunity

For each:

- what it is
- why it could be powerful
- rough scale
- scored evaluation

End with a clear recommendation:

- original idea
- one alternative
- or a hybrid
