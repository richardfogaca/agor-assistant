# Review Criteria

Use these evaluation areas during `cy-review-round`:

- Security
- Correctness
- Concurrency
- Performance and Scalability
- Error Handling
- Code Quality and Maintainability
- Testing
- Architecture
- Operations

Severity guidance:

- `critical`: merge-blocking correctness, security, or data-safety failure
- `high`: significant deviation from requirements, contracts, or safety
- `medium`: meaningful maintainability, edge-case, or verification gap
- `low`: minor but real issue worth tracking if signal remains strong
